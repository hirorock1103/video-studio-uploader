プライバシーポリシー

video-studio uploader（以下「本ツール」）は、運営者が自分の YouTube チャンネルを管理するための個人用ツールです。

  • 本ツールは Google アカウントの認可を通じて YouTube Data API にアクセスし、運営者自身のチャンネルへの動画のアップロード、動画情報の更新、再生数などの統計の取得だけを行います。
  • 取得した情報は運営者のパソコン内にのみ保存し、第三者に提供・販売・共有することはありません。
  • 本ツールの YouTube API の利用は YouTube 利用規約 と Google プライバシーポリシー に従います。
  • 認可は Google アカウントの権限設定 からいつでも取り消せます。

Privacy Policy

video-studio uploader ("the tool") is a personal tool used by its owner to manage the owner's own YouTube channels.

  • The tool accesses the YouTube Data API through Google OAuth only to upload videos to, update video details on, and read statistics for the owner's own channels.
  • Data obtained is stored only on the owner's computer and is never sold, shared with, or provided to third parties.
  • Use of the YouTube API follows the YouTube Terms of Service and the Google Privacy Policy.
  • Access can be revoked at any time from Google Account permissions.
